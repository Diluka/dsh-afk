# dsh-afk

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供离开模式。暂时离开时，让 Agent 按你的设置自动应答或停止提问，回来后再查看提问记录。

## 功能

- **自动应答**：用自定义文本回复新提问，不替你选择选项。
- **禁用提问**：关闭提问工具，让 Agent 在已有授权范围内自行判断。
- **全局或按会话设置**：可统一当前 profile 的配置，也可让各会话独立；默认关闭。
- **提问记录**：无论 AFK 是否开启，都保存当前会话的结构化提问与结果。默认只看未读，标记已读后仍可在「全部」中回看。

## 安装

当前支持 **DSH 0.2.1-rc.2**。

在 DSH 插件管理器中安装 `github:Diluka/dsh-afk`，或使用 CLI：

```bash
dsh plugin --profile web add "github:Diluka/dsh-afk"
```

将 `web` 换成你的目标 profile。安装后按宿主提示刷新页面；需要重启时，先保存正在进行的工作。

## 使用

1. 打开 **插件 → AFK · 会话离开模式**，选择「按会话单独」或「全局统一」，再设置处理方式和自动应答语。
2. 离开前打开输入框权限设置旁的 **AFK** 开关，回来后关闭。全局模式的开关显示为 **AFK · 全局**，影响当前 profile 的所有会话。
3. 点击开关旁的 **记录** 查看提问和结果。数字表示未读批数；点击某条的「已读」后，该条从默认列表隐藏，但不会删除。

切换作用范围会保留各会话原配置；提问记录与已读状态始终按会话独立。修改自动应答语也不会覆盖旧记录中的实际回复。

> [!IMPORTANT]
> AFK 不会批准权限请求、批准计划或扩大已有授权。自动回复带有明确的 AFK 标识，不代表人类作出了选择或确认。
>
> 只影响新派发的提问，不接管已在等待的问题；禁用提问时，没有实际发出的问题无法记录。AFK 不会自动重启已结束的任务。
